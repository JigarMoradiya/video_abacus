#
#  1. THE TRICK. Big friend taking away is −n = +friend −10 (E13): ADD the friend f = 10−n to the
#     ones digit d, then take one bead off the tens rod. Needed when d < n (not enough to take away).
#     Because d < n, d + f ≤ 9, so the ones rod never overflows — the only question is whether
#     "add f" is a PLAIN move (only beads that switch on: lower beads up, upper bead down).
#     "Add f" is plain when f fits in the free lower beads (f ≤ 4 − d), or f ≥ 5 and the upper bead is
#     up and the rest fit. It is NOT plain when the upper bead is up (d < 5), f ≤ 4, and f > 4 − d:
#     there are not enough free lower beads. Then the SMALL friend adds f for us:
#         +f = −(5−f) +5        (E08/E09 small friend adding: e.g. +4 = −1 +5)
#     So Family Minus = big friend + small friend:
#         −6 = +4 −10, and +4 = −1 +5   →  −6 = −1 +5 −10
#         −7 = +3 −10, and +3 = −2 +5   →  −7 = −2 +5 −10
#         −8 = +2 −10, and +2 = −3 +5   →  −8 = −3 +5 −10
#         −9 = +1 −10, and +1 = −4 +5   →  −9 = −4 +5 −10
#     Lower beads taken off first are always n − 5 (= 5 − friend).
#
#  2. WHEN (exact; brute force over every ones digit d for every n; trigger d < n):
#         formula   friend   FAMILY when ones digit d is     pure big friend when d is
#         −6        4        1, 2, 3, 4                       0, 5
#         −7        3        2, 3, 4                          0, 1, 5, 6
#         −8        2        3, 4                             0, 1, 2, 5, 6, 7
#         −9        1        4                                0, 1, 2, 3, 5, 6, 7, 8
#         −1 … −5   —        NEVER (friend ≥ 5 fits, or enough free lower beads)
#     Your claim was right: Family only when d < 5 and 4 − d < f ≤ 4. 10 (d, n) pairs — exactly the
#     app's familySubPairs() (iOS Level2Content.swift:249: 11−6 12−6 13−6 14−6, 12−7 13−7 14−7,
#     13−8 14−8, 14−9). The pure-big-friend column matches the ranges already used for the Math
#     Heroes taking-away shorts. In kid words: "the ones rod has no room to add the friend."
#     The mirror of E15: Family PLUS needed d ≥ 5 (upper bead down); Family MINUS needs d < 5 (upper
#     bead UP) — so the upper bead is up, and the free lower beads run out.
#
#  3. NOTATION / ORDER. The app (iOS Level2FormulaView.swift "Family − (+5−10)", rows
#     "−6 = −1+5−10" … "−9 = −4+5−10", Android the same) writes the formula in exactly the series order:
#     ones rod first, LOWER beads before the upper bead, tens rod last. E16 speaks it that way: "Minus
#     six equals minus one, plus five, minus ten." FLAG: the app's beadMoves TEXT for the same rows
#     reads "Borrow → heaven down → remove 1 earth" (borrow FIRST), and its learn step says "Borrow from
#     tens (−10), push heaven DOWN (+5), remove 1 earth (−1)". That is the wrong order for the series
#     (the formula notation is right, the move text is not). Physically the lower-first order is legal
#     because the lowers removed (5−f) never exceed d exactly when f > 4−d (the Family condition).
#
#  4. DIRECTION OF EVERY MOVE (finger rule: UP = thumb, DOWN = index finger, decided by direction):
#         "minus <k> lower beads"  → lower beads pushed DOWN (away from the beam)  → INDEX finger
#         "plus five"              → upper bead pushed DOWN toward the beam         → INDEX finger
#         "minus ten" (the borrow) → one bead on the tens rod pushed DOWN           → INDEX finger
#     All Family Minus MOVES are DOWN moves: the mirror of E15 (all UP, thumb). Number MAKEUP is the
#     usual mix: lower beads pushed UP (thumb), the upper bead pushed DOWN (index finger).
#

# --- 2 · THE PUZZLE — the wall comes first: 11 − 6 ---
Make eleven. One lower bead on the ones rod, and one lower bead on the tens rod. Thumb pushes them up.
Six's friend is four. The big friend says: add four to the ones rod, then take ten off the tens rod.
Quick guess. Is there room for four more lower beads on the ones rod?

Nope! Only three fit.
Whoa. The big friend is stuck.

# --- 3 · WHY, THEN THE NAME, THEN THE ROUTINE — need before name ---
Why? The upper bead is up, and the lower beads are almost full. No room to add four.
Who can help?
# ⏸ hold 3s
The small friend! Four's small friend is one.
To add four: take away one, then add five.
The big friend and the small friend, side by side. That team is called the family.
# ⏸ hold 1s
Here is our routine. Look. Call. Move.
Look: room on the ones rod? Call: no room, call the family. Move: ones rod first.
# ⏸ hold 2s

# --- 4 · THE FORMULA, THE MIRROR, THEN THE BEADS: 11 − 6 ---
The big friend says: minus six equals plus four, minus ten.
The small friend swaps plus four for minus one, plus five.
So the family says: minus six equals minus one, plus five, minus ten.
# ⏸ hold 3s
Why? Minus ten takes four too many. So we add four back first.
# ⏸ hold 1s
Now remember last time. Plus six was plus one, minus five, plus ten. What changed today?
# ⏸ hold 3s
Every sign flipped! It is a mirror.
So which finger now, thumb or index?

Boom! Eleven take away six is five.
