# Math Heroes — recording script (9:16 short reel, ~40-45s)
# Lines starting with # are notes and are NOT read aloud — same rule the full episode scripts
# use. Everything else IS read aloud, exactly as written.
#
# Two voices: NARRATOR and BLAZE and SPARK. A "# BOTH" line means Blaze and Spark read that one
# line together (or, if you only have one voice, just read it once yourself — it still works).
# Read at a quick, energetic pace — this is a short-form hook, not a slow lesson.

# NARRATOR
When a number gets stuck, Math Heroes save the day!

# BLAZE
Alert! Three plus two, and it's stuck!

# SPARK
There's no room to add two. Let's call a friend!

# hold silent ~3s here for the mission-timer countdown (3, 2, 1) — nothing spoken

# SPARK
Two's friend is three!

# BLAZE
Take away three, then add five!

# BOTH
Three plus two is five! Mission solved!

# BLAZE
Another alert! Four plus one, and it's stuck!

# SPARK
There's no room to add one. Let's call a friend again!

# hold silent ~3s here for the mission-timer countdown (3, 2, 1) — nothing spoken

# SPARK
One's friend is four!

# BLAZE
Take away four, then add five!

# BOTH
Four plus one is five! Heroes win again!

# NARRATOR
Every stuck number has a trick. Learn them all with Abacus Kids — free on the App Store and Google Play!
