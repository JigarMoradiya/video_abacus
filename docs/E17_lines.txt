# ═══ GAME DESIGN (approved) ═══  ONE job every round: "Which step is missing?" Every family trick is
#   three bead steps in the series order — the LOWER-BEAD part, the FIVE part, the TEN part:
#         plus  family:  +(n−5)  −5  +10          e.g. +6 = +1 −5 +10     (all steps UP → thumb)
#         minus family:  −(n−5)  +5  −10          e.g. −6 = −1 +5 −10     (all steps DOWN → index finger)
#   ONE part is hidden ("blank"). The viewer picks A, B or C (read aloud, 3 s hold), then the answer.
#   The question wording is identical every round so kids learn the rhythm: "<formula with a blank>.
#   Which step is missing? A: … B: … C: …". Wrong choices are plain numbers, never a bead-order move.
#   Which part is hidden varies (lower-bead ×3, five ×3, ten ×2, never the same part twice in a row);
#   the answer letter varies too. Eight rounds, one per family formula, random order. Narration is
#   maths only (numbers, rods, beads, steps, fingers); any world/mascot idea lives in the visuals.
#   Each round: "Round …", a Make line, the formula with a blank, the question, the answer, then "Move"
#   with the three steps as three short lines, then the sum. Look, Call, Move (E16) is a one-line callback
#   in the hook, not re-taught. No boss round (runtime), no spot-the-mistake, no card matching.
#
# ═══ DELIBERATE EXCEPTION TO THE CHECKLIST ═══  Rounds carry a Make line but NO separate "friend" line
#   ("Seven's friend is three"): the approved game shows the three steps and hides one, and a friend line
#   per round would add about 20 s. The friend is implied by the lower-bead part (n − 5) and the formula.
#   Flagged to the coordinator; adding it back costs ~20 s of runtime.
#   Repeated words ("Round …", "Move.", "Which step is missing?") are the deliberate game rhythm.
#
# ═══ FORMULAS (friend-first, lower-first; n and friend checked) ═══
#   +6 = +1 −5 +10   +7 = +2 −5 +10   +8 = +3 −5 +10   +9 = +4 −5 +10     (friend 4, 3, 2, 1)
#   −6 = −1 +5 −10   −7 = −2 +5 −10   −8 = −3 +5 −10   −9 = −4 +5 −10     (friend 4, 3, 2, 1)
#   Family PLUS needs ones digit d ≥ 5 (+6: 5–8, +7: 5–7, +8: 5–6, +9: 5). Family MINUS needs d < 5
#   (−6: 1–4, −7: 2–4, −8: 3–4, −9: 4). Directions: plus family moves are all UP (lower beads up, the
#   five = upper bead pushed up, the ten = tens bead up) = THUMB; minus family moves are all DOWN = INDEX
#   finger. Number makeup is the usual mix: lower beads UP (thumb), upper bead DOWN (index).
