# ═══ CONTENT ═══

# THE MIRROR OF E08. Adding ran out of lower beads going UP; subtracting runs out going DOWN —
# there are not enough lower beads left to take away. The fix is the same friends, used backwards:
# ADD the friend to the lower beads first, THEN take away five by releasing the upper bead.
#
# BOTTOM BEADS FIRST, STILL. E06's rule is about the MOVE, not the operation: lower beads move
# before the upper bead, always. So the notation is `−n = +friend −5`, friend-first, exactly
# mirroring E08's `+n = −friend +5`. Checked for every case: adding the friend to the lower beads
# never exceeds four, because the trigger condition (digit%5 < n) guarantees (digit%5 + friend) <= 4.
#
# THE FOUR CASES, the only digit each one is possible from (single rod, digit 5-9):
#   −1 = +4 −5   only from 5            (5 − 1 = 4)
#   −2 = +3 −5   from 5 or 6            (6 − 2 = 4)   WE SHOW
#   −3 = +2 −5   from 5, 6 or 7         (6 − 3 = 3)   THEY DO
#   −4 = +1 −5   from 5, 6, 7 or 8      (7 − 4 = 3)   WE SHOW
#
# −1 IS THE WALL, not a fourth "we show" — it is only ever possible from a rod showing exactly
# five, which is ZERO lower beads: the starkest possible stuck moment, and the natural hook.
# −3 is the your-turn, on its own digit (6), not reusing the wall's 5 — this episode has no prior
# taught case to lean on the way E08 leaned on E07's +3, so the your-turn is genuinely new work,
# not recall.
#
# THE CONTRAST CASE: nine minus two. digit%5 = 4 >= 2, so this is DIRECT — take two lower beads
# away, no friend needed. Establishes the trigger (look at the lower beads first) exactly as
# E08's "two plus two" did.
#
# ONE ROD ONLY. Every result stays under ten.
