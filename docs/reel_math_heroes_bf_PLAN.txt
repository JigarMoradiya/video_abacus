WHY +5/-5 ARE SPLIT OUT
------------------------
Big Friend has 9 add formulas and 9 subtract formulas. 4+4 covers 8 of 9 per
direction, leaving exactly one uncovered each time. +5 and -5 are the natural
leftovers because 5 is its own friend (friend = 10-5 = 5) — they don't pair
with a different number the way the other four pairs do (1<->9, 2<->8, 3<->7,
4<->6), so forcing either into shorts 1-4 would make one of those shorts
teach an awkward 5th "odd" formula instead of a clean pair-based set of 4.
Instead, +5 opens Short 5 and -5 opens Short 6 — each gets its own moment in
a mixed-operation reel, and each mixed reel fills its remaining 3 missions
with formulas already taught earlier, on brand-new two-digit numbers (recall
practice, not new teaching).

THE DIRECT-MOVE VALID-d RANGES (ones digit d before the move, friend f=10-n)
-----------------------------------------------------------------------------
ADD +n (trigger: d+n>9, i.e. no room to add n directly — call friend f, then
+10 on tens rod. Direct iff the ones rod has >=f beads to remove):
  +1 -> d in {9}
  +2 -> d in {8,9}
  +3 -> d in {7,8,9}
  +4 -> d in {6,7,8,9}
  +5 -> d in {5,6,7,8,9}
  +6 -> d in {4,9}
  +7 -> d in {3,4,8,9}
  +8 -> d in {2,3,4,7,8,9}
  +9 -> d in {1,2,3,4,6,7,8,9}

SUBTRACT -n (trigger: d<n, i.e. not enough to take away n directly — call
friend f, add it, then -10 on tens rod. Direct iff the ones rod has room to
add f without overflow):

  -2 -> d in {0,1}
  -3 -> d in {0,1,2}
  -4 -> d in {0,1,2,3}

RUNTIME ESTIMATE PER SHORT
----------------------------
Baseline: the existing 2-mission shorts (short_math_heroes.tsx /
short_math_heroes_2.tsx) run approximately 55-60s for 2 missions, i.e.
roughly 27-30s per mission including its alert/stuck/countdown/friend-reveal/
formula/solved beats and the ~3s held countdown pause.
Cross-check against E14's own round-reveal pacing: each round there runs
roughly 8-12s for the reveal/formula/solved beats alone (excluding the
wheel-spin/build phase, which the Math Heroes format doesn't use at all —
it goes straight from alert to countdown to reveal). Adding the Math Heroes
format's ~3s countdown hold and the alert/stuck setup lines brings each
mission to a comparable ~27-30s total, consistent with the 2-mission
baseline's own per-mission math (55-60s / 2 ~= 27.5-30s).
At 4 missions per short (this new set), with no other structural change:
  4 x ~27-30s/mission = ~108-120s per short, plus the shared opening narrator
  line (~2-3s) and closing CTA line (~4-5s) common to all shorts
  => estimated total runtime per short: ~115-130 seconds (about 2-2.2 minutes).
This roughly doubles the original ~55-60s runtime, as expected for exactly
double the missions (2 -> 4) with the same per-mission beat structure, pacing,
and countdown hold carried over unchanged.

PRODUCTION FLAG — SINGLE-ROD VS TWO-ROD ABACUS PROP
------------------------------------------------------
short_math_heroes.tsx hardcodes a single floating abacus rod for the prop:
  ABX_BOX: rodCount: 1, innerW: 1 * ROD_PITCH * ABX_SCALE
  <Abacus rods={[{ value: bead.to, from: bead.from, focus: 1 }]} .../>
and positions the formula card in the wide open margin beside that single
rod (FORMULA_LEFT = ABX_LEFT + ABX_W + 36). This layout assumes a single-digit
number on one rod with generous clear space on both sides.
Big Friend's 24 examples are all genuine two-digit numbers requiring a TENS
rod and a ONES rod moving together (the full "-friend+10" / "+friend-10"
two-rod move, same geometry already used in E11-E14). The existing single-rod
prop and its wide-margin formula-card layout will NOT directly accommodate
this — it needs to become a 2-rod floating prop (matching E11-E14's own
place-value/rod geometry), and the formula card's margin will likely need to
narrow or reflow to make room for the second rod.
This is flagged for a decision before any production (code/render) work
starts on these shorts — not resolved in this script-only pass.

DIFFERENTIATION PASS (revision 2 — all 24 numbers/formulas above unchanged)
-----------------------------------------------------------------------------
First draft of all 6 scripts used one identical mechanical template (alert ->
mission x4 -> close) with only the numbers swapped, which read as 6
interchangeable shorts. Revised per house rule (every new short reel needs
its own hook in the first 3-4s and must never reuse a prior reel's theme).
Each short now has a distinct setting/hook, its own stuck/win vocabulary, and
varies who gets stuck vs. who calls the friend each mission:
  Short 1 — arcade grand-opening morning, jammed ticket counter. Blaze stuck
            every mission, Spark calls each friend. Vocab: jammed/maxed out/
            stuck solid -> prints out/rolling/ticket's out.
  Short 2 — closing time, five minutes to the bell, frozen scoreboard. Roles
            swapped from Short 1: Spark stuck every mission, Blaze calls the
            friend. Vocab: frozen/freeze/packed tight -> scoreboard's back/
            keep it moving/bell's ringing.
  Short 3 — near-empty prize wall, ticket countdown glitching. Calmer tone;
            Blaze and Spark alternate who's stuck mission to mission. Vocab:
            glitch/glitching/stuck on empty -> counter's good/ticket wall's
            steady/jackpot.
  Short 4 — storm rescue, chopper dial board locked mid-flight. Highest-
            urgency, clipped lines; roles alternate (opposite pattern from
            Short 3). Vocab: locked/locked tight/won't budge -> dial's free/
            keep climbing/landed, everyone's safe.
  Short 5 — NOT a crisis: a calm "check-up" speed drill between missions, no
            alert framing at all. Vocab: drill one/two/three/last drill ->
            check!/full check, no misses.
  Short 6 — the other recall short flipped into a high-energy "lightning
            round" against a running clock (contrast with Short 5's calm
            drill, so the two recall shorts don't repeat the same framing).
            Vocab: no room/not enough/stuck -> next!/one left!/perfect score.
Reaction-line phrasing for "stuck," "friend reveal," and "celebration" was
also varied per mission within each short (not the same 3 lines reused 4x),
and plain/expressive diffs plus the stray-digit check were re-run after the
rewrite — both still pass clean (see the main verification note above this

COLD-OPEN FIX (revision 3 — hook lines only, story settings unchanged)
-------------------------------------------------------------------------
Revision 2's opening lines hooked the STORY (arcade, scoreboard, storm, prize
wall) but dropped the explicit "this is about a stuck number" signal the
original two Math Heroes shorts led with in their very first line ("When a
number gets stuck, Math Heroes save the day!" — checked directly against
docs/reel_math_heroes_lines.txt / reel_math_heroes_2_lines.txt as precedent).
Without that, a viewer had no signal in the first 3-4s that this was abacus/
math content rather than a generic cartoon. Fixed by weaving "a stuck number"
into each short's own opening line, so the hook now does both jobs (story +
math) at once instead of making the viewer wait for the first mission's
numbers several lines later:

  Short 3: "Prize wall's almost empty, and a stuck number's blocking the

           chopper's dial board!"

           stuck-number check-up, no alarms this time, just a friendly
           speed drill."
  Short 6: "Lightning round! One minute on the clock, Blaze and Spark race
           the timer through four stuck numbers back to back."
Only these NARRATOR opening lines changed; everything else from revision 2
(per-short setting, hero-role pattern, mission vocabulary, closing CTA) is
unchanged. Plain/expressive diffs and the stray-digit check were re-run
again after this edit — both still pass clean for all 6 shorts.

LANGUAGE / MATH-BALANCE PASS (revision 4 — numbers/formulas/structure unchanged)
-----------------------------------------------------------------------------------
Revision 2's differentiation pass had let story jargon crowd into the MATH
lines themselves, not just the alert/celebration lines, and used some words
too complex for the app's actual audience (young kids learning abacus):
"dial"/"the ones dial" (not an abacus term a kid knows), "glitch"/"glitching"
(tech jargon), "maxed out"/"packed tight"/"locked tight"/"won't budge"
(adult-register phrasing), and invented reveal verbs ("clear X, roll a new
ten" / "bump the ten" / "drop a ten") that varied the SAME math instruction
six different ways instead of keeping it simple and recognizable.
Fixed by rebalancing every mission so the math is always the clear
through-line and the story setting is only flavor in the alert/celebration
lines:
  - Every mission's core instruction is now one of exactly two plain,
    uniform phrasings, matching the original two Math Heroes shorts'
    own phrasing style: "Take away [friend], then add ten!" for an ADD
    round, "Add [friend], then take away ten!" for a SUBTRACT round.
  - Every "stuck" line is now the same simple word ("is stuck!" / "There's
    no room to add ___." / "There's not enough to take away ___.") instead
    of six shorts' worth of different synonyms competing with the numbers.
  - Story-setting words ("ticket counter," "scoreboard," "prize wall,"
    "rescue chopper," "drill," "lightning round") now appear ONLY in each
    short's alert line and celebration line, never inside the friend-reveal
    or operation lines.
BEFORE / AFTER examples (verbatim from the files):
  Short 1, Mission 1 — before: "No room on the ones dial. Only one fix,
    call the friend!" / "Clear nine, roll a new ten!"
    after: "There's no room to add one. Let's call a friend!" / "Take away
    nine, then add ten!"
  Short 2, Mission 2 — before: "Dial's packed tight. Friend, quick!"
    after: "There's no room to add seven. Friend, quick!"
  Short 3, Mission 1 — before: "Sixty tickets left, take away one, glitch!
    Can't go below zero on the ones!"
    after: "Sixty take away one is stuck!"
  Short 4, header/narrator — before: "...the rescue chopper's dial board
    just locked up, the numbers won't budge!"
    after: "...a stuck number is blocking the rescue chopper!"
Numbers, formulas, direct-move results, mission count, hero-role patterns,
per-short story identity, and the math-signaling hooks from revision 3 are
all unchanged — this was a wording/balance pass only. Plain/expressive
diffs, the stray-digit check, and a fresh grep for leftover jargon ("dial",
"glitch", "jammed", "maxed out", "packed tight", "locked tight", "won't
budge", "frozen solid") were all re-run after the rewrite — all clean
(the one hit on "jammed" is in Short 1's alert line only, a simple concrete
word kids already know, not mid-complexity jargon, so it was kept).
