# Math Heroes · Big Friend 4 — recording script (9:16 short reel)
# Lines starting with # are notes and are NOT read aloud. Everything else IS read aloud.

# THIS SHORT'S HOOK: A storm is rolling in and a stuck number blocks the rescue chopper. Highest
# urgency of the set. Alert/celebration lines carry the setting; every math line is plain wording
# ("stuck" / "not enough to take away" / "add ___, then take away ten").
#
# FORMULA SPLIT (revision 9): BIG FRIEND TAKING AWAY, the other random half: −2, −4, −7, −9 (mix of
# small and big numbers). Short 3 has −1, −3, −6, −8; −5 is in short 6. Friend-first: −n = +friend − 10.
#
#   Mission 1:  37 − 9   friend 1   -> 28
#   Mission 2:  23 − 4   friend 6   -> 19
#   Mission 3:  36 − 7   friend 3   -> 29
#   Mission 4:  41 − 2   friend 8   -> 39
