# SECOND of the foundational reels (after Bead Values, before Counting 1-10). Locked rule,
# straight from the app's own tour: the finger is decided by DIRECTION, never by which bead.
# Addition: thumb pushes lower beads UP, index finger brings the upper bead DOWN.
# Subtraction: index finger sends lower beads DOWN, thumb brings the upper bead UP.

Want to move beads like a pro? Let's learn the secret fingers!
Going up always uses your thumb.
Watch — thumb pushes this lower bead up!
Going down always uses your index finger.
Watch — index finger brings the upper bead down!
It's the same rule for taking away — index finger going down, thumb going up!
Up is thumb. Down is index finger. Every single time!
